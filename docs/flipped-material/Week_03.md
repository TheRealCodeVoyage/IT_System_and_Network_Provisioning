## Introduction to Terraform
We're transitioning from imperative commands — the bash scripts and AWS CLI calls we've used so far — to declarative configuration files using HashiCorp Terraform. Where you've been telling AWS exactly what steps to run, Terraform lets you describe the end state you want and figures out the steps itself.

From the O'Reilly video collection **"Terraform in AWS from Basics to Guru"** by David Prowse and Chad Smith, watch:
