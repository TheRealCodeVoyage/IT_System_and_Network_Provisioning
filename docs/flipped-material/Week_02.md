# Week 2 Flipped Material

**Complete this before Week 3's class.** Next week we transition from local development environments to provisioning resources in the public cloud — Quiz2 at the start of Week 3 covers this reading plus a recap of this week's lecture.

## 1. Introduction to the AWS CLI
The AWS Command Line Interface is a unified tool for managing your AWS services. One tool to install and configure gives you control over every AWS service from the command line, and — more importantly for this course — lets you automate that control through scripts.
- **Read:** [What is the AWS Command Line Interface?](https://docs.aws.amazon.com/cli/latest/userguide/cli-chap-welcome.html)

## 2. Navigating Help and Resources
Cloud services change quickly, so knowing how to use the CLI's built-in documentation is a durable skill — one that outlasts any specific tutorial. You should be able to find the required arguments for any command without defaulting to a search engine.
- **Read:** [Accessing help and resources for the AWS CLI](https://docs.aws.amazon.com/cli/latest/userguide/cli-usage-help.html)

## 3. Authentication
Before you can run commands against your AWS account, the CLI needs to know who you are. We'll use IAM (Identity and Access Management) credentials — an Access Key ID and Secret Access Key — to authenticate your local environment.
- **Read:** [Authenticating using IAM user credentials for the AWS CLI](https://docs.aws.amazon.com/cli/latest/userguide/cli-authentication-user.html)
